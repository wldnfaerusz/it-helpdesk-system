# IT Helpdesk System

Sistem IT Helpdesk terintegrasi berbasis web untuk manajemen tiket, pemantauan status perangkat, dan layanan bantuan IT.

## 🚀 Fitur Utama
- **Dashboard & Analitik**: Ringkasan tiket, performa tim, dan metrik penanganan masalah.
- **Manajemen Tiket**: Pembuatan tiket baru, filter prioritas/status, dan riwayat komplain.
- **Monitoring Aset & Perangkat**: Status kesehatan hardware/software jaringan.
- **User Management**: Manajemen peran teknisi, admin, dan user umum.

## 🛠️ Cara Menjalankan
Cukup buka file `index.html` langsung di browser Anda, atau gunakan live server/web server lokal.
